# v2.2 十分钟讲解提纲

用于复习与自测，提供提纲不等于已完成个人讲解验收。

1. 任务与指标：Logistic 与线性奖励；动态伪遗憾相对每一步当时的最优臂。
2. OMD / DOMD：梯度步、局部度量、球投影；折扣曲率和正则项；完整策略比较与 γ 消融的区别。
3. SCB：折扣 MLE、历史存储、数值投影；局部 KKT 与全局最优的区别。
4. 实验设计：验证选参、预留测试、固定流与闭环；特征组与奖励种子；均值排名与统计不确定性。
5. 变化环境：直线插值经过零、恒范数旋转、DOMD 的优势边界。
6. Hvt：已知中心矩、σ 归一化、τ 裁剪、V 更新及投影；零裁剪次数和原常数版负结果的含义。
7. 工程证据：策略数组、保留历史、日志、RSS；校验和、指标重算和动作回放分别验证什么。

参考：[公式映射](v2_2_formula_map.md)、[实验说明](v2_2_remaining_experiments.md)、[最终报告](../reports/v2_2/release/report.md)。
