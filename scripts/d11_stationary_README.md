# E11 固定实验入口

在项目根目录运行一次 `python scripts/d11_stationary.py`。
只新增脚本、7项策略回归和本说明，不覆盖现有估计器或策略核心。
复用d8归档函数和现有RandomPolicy。

先全套pytest，再对Random和paper_v2_literal分别做50轮smoke与一次精确重放；
通过后运行d=3、K=10、T=1000、seeds=0..4的10条正式轨迹。
动作特征固定为种子20261001生成的单位向量；真参数仅在环境和评估器中使用。
参数固定：eta=3、lambda=126、S=2、delta=0.05。

固定维度与动作数，另外测量T=200/1000/5000，每个长度3个seeds。
计时包装仅用于规模测量，按选择、更新总计、更新内线性求解、其余更新和CSV行写入分别记录。
投影整体计时与线性求解有重叠，不能相加。计时有测量开销，不是复杂度证明。
状态数组载荷不代表峰值内存。

置信公式来源：arXiv:2507.11847v2，PDF p6正文与p14附录A.1存在时间因子差异。
本次按正文原样paper_v2_literal运行；不替换为附录形式、不缩放置信系数。
把该结果描述为字面公式的工程复现，不宣称已解决论文理论歧义。

输出包含逐轮CSV、时间记录、配置、最终参数、两张图、观察说明、pytest日志及源码哈希。
唯一results目录会复制至reports/d11，并生成evidence.zip。
如失败，保留现场后停止；不自动重试。
如果运行成功，返回终端摘要和evidence.zip，不重复执行。
